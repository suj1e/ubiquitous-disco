# PR Blacklist

记录反复提交低质量或恶意代码的账号。黑名单账号提交的 PR 需要额外证据才能合并。

## 判定标准

同一账号出现下列情况之一，且经确认后可记入：

1. 多次提交无法构建或无法运行的代码，且未自行验证。
2. PR 描述与实际改动不符，或声称已测试但实际未测试。
3. 提交重复、抄袭，或明显由未审阅的 agent 生成且无人负责的代码。
4. 提交恶意代码：后门、凭证窃取、静默外联、挖矿、破坏性脚本。
5. 在 PR 中夹带与描述无关的改动。

## 处理方式

- 首次出现：回复 PR 说明问题并要求修正，不记入黑名单。
- 重复出现：记入本表，并在后续 PR 中要求额外证据。
- 恶意代码：直接关闭 PR 并记入本表，不进入正常审查流程。
